How to open

  1. Open local SAMMI with the button below.
  2. In SAMMI, choose Load SAMMI Model.
  3. Select sammi_native_session.json from this output folder.

Common failure checks

  • If local SAMMI does not open, configure SAMMI_STANDALONE_HOME or use the lightweight viewer.
  • If SAMMI opens but the map is empty, confirm you selected this export's sammi_native_session.json.
