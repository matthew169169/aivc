# Omics-GEM Studio 详细使用手册

更新时间：2026-05-21

## 1. 软件定位

Omics-GEM Studio 是一个面向多组学数据整合进 GEM / GSMM 的工作台。它的目标不是只运行某一个算法，而是把以下步骤组织成可解释、可复现的流程：

```text
数据管理 -> 证据准备 -> 模型变体生成 -> 分析选择 -> 报告与可视化
```

目前主要包含：

- 多组学数据上传与 run package 管理
- model variant registry
- transcriptomics / proteomics / consensus evidence
- E-Flux / Delta-FBA-lite
- TROPPO FASTcore context model
- UniProt / GPR model check
- kcat / DLKcat bridge
- GECKO-ready export
- FBA / pFBA / optional FVA
- PCA / LASSO-lite / MINN-style export
- Production Analysis / ecFactory-lite / FSEOF-lite
- SAMMI-compatible visualization package
- FastAPI + React + Electron 桌面壳

## 2. 安装方式

### 2.1 推荐：Windows 安装器

发送或运行：

```text
D:\generate\desktop_installer\Omics-GEM-Studio-Setup.exe
```

安装器会分发：

- Electron desktop runtime
- React 前端
- FastAPI 后端源码
- `omics_router` 核心模块
- bootstrap / repair 脚本
- `requirements.txt`
- 启动脚本

安装后入口会先运行 runtime launcher，再由 launcher 调用：

```text
tools\bootstrap_desktop_env.ps1 -RuntimeOnly -Mode Minimal
```

然后启动桌面界面。

### 2.2 便携 zip

发送：

```text
D:\generate\desktop_installer\Omics-GEM-Studio-runtime-staging.zip
```

解压后运行：

```text
start_omics_gem_studio.bat
```

### 2.3 开发者源码模式

如果是在当前项目目录中运行：

```powershell
cd D:\generate
.\start_omics_gem_studio.bat
```

开发者也可以分别启动：

```powershell
python -m uvicorn api.main:app --host 127.0.0.1 --port 8765
cd frontend
npm.cmd run dev
```

普通用户不需要这种方式。

## 3. 系统依赖

### 3.1 会自动处理的部分

软件可以通过 bootstrap / repair 自动准备：

- 项目本地 `.venv`
- Python 基础依赖
- FastAPI 后端运行依赖

Minimal 模式安装 `requirements.txt`。

Full 模式可安装 `requirements-optional.txt` 中的部分可选 Python 依赖。

### 3.2 不自动安装的外部依赖

以下依赖不会自动安装，只做检测、配置和引导：

| 依赖 | 用途 | 是否必需 |
| --- | --- | --- |
| MATLAB | GECKO / MATLAB runner | 可选 |
| GECKO_HOME | 酶约束模型 GECKO workflow | 可选 |
| RAVEN / COBRA Toolbox | MATLAB 生态模型工具 | 可选 |
| solver | 高级优化求解器 | 可选 |
| PYTFA_THERMO_DB | pyTFA thermodynamic workflow | 可选 |
| SAMMI_STANDALONE_HOME | 本地 standalone SAMMI 资源 | 可选 |

在 `Settings -> External Tools & Licensed Dependencies` 中可以查看这些依赖状态。

## 4. 主界面说明

### 4.1 语言

默认语言：简体中文。

切换位置：

- 顶部右侧 `语言 / Language`
- 左侧 sidebar 底部 `语言 / Language`

选择会保存到浏览器 / 桌面 localStorage：

```text
omics-gem-ui-language
```

内部 API 字段、CSV schema、文件名仍保持英文，避免破坏 pipeline。

### 4.2 DataHub

DataHub 用来管理 run package。

可以查看：

- active runs
- archived runs
- example presets
- input files
- model variants
- report files
- visualization packages
- import manifest

常用动作：

- 打开 run folder
- 查看 import manifest
- copy example to workspace
- archive run
- restore archived run

archive / restore 都是安全操作，会写入 job/log，不做永久删除。

### 4.3 Workflow Studio

Workflow Studio 是模型生产与分析的入口。当前重点是展示 workflow/API 状态，完整 pipeline 异步化仍是后续方向。

核心产品逻辑是：

```text
Upload & Setup
Evidence Preparation
Model Generation
Analysis Selection
Report Builder
```

当前 React 桌面版主要把已经生成的 run package、variants、reports、visualizations 串起来；更完整的模型生产操作仍保留在已有 pipeline / Streamlit 体系和后端函数中。

### 4.4 Visualization Studio

Visualization Studio 用于生成 SAMMI-compatible visualization package。

可选择：

- run
- model variant
- grouping mode
  - `subsystem`
  - `compartment`
  - `selected_reactions`
- overlay source
  - `none`
  - `transcriptomics_evidence`
  - `relative_proteomics`
  - `consensus_evidence`
  - `fba_flux`
  - `production_ranking`
  - `uniprot_gpr_warning`
  - `custom_overlay`

输出目录一般为：

```text
user_runs\<run_id>\visualization_results\sammi\<variant_id>\
```

关键输出：

```text
subsystem_reaction_assignment.csv
subsystem_summary.csv
overlay_data.csv
overlay_summary.csv
sammi_map_package.json
sammi_package_manifest.json
sammi_assets_status.csv
standalone_readme.html
sammi_launch.html
```

注意：当前版本生成的是 SAMMI-compatible package，还不是直接渲染 PNG/SVG 网络图片。

### 4.5 Task Center

Task Center 显示 job 历史和日志。

常见 job type：

- `sammi_visualization`
- `report_bundle`
- `backend_environment_repair`
- `run_archive`
- `run_restore`
- `pipeline`

如果某个操作失败，优先到 Task Center 查看 job log。

### 4.6 Settings

Settings 主要用于查看环境状态。

包含：

- API health
- Python backend readiness
- desktop runtime status
- installer / staging manifest
- external tools readiness
- backend repair / dry-run repair

GECKO/MATLAB/SAMMI standalone 等高级依赖在这里配置和检测。

## 7. 常见问题

### 7.1 打开后看不到中文语言选项

请确认使用的是新版 runtime 或新版 installer。

推荐启动：

```powershell
cd D:\generate
.\start_omics_gem_studio.bat
```

如果是安装版，请重新运行：

```text
D:\generate\desktop_installer\Omics-GEM-Studio-Setup.exe
```

语言控件在顶部右侧和左侧 sidebar 底部。

### 7.2 Settings 显示 MATLAB / GECKO missing

这是正常的。MATLAB / GECKO 是可选高级依赖。基础 DataHub、Visualization Studio、SAMMI-compatible package 不需要它们。

如果要用 GECKO：

1. 安装 MATLAB。
2. 下载 GECKO。
3. 在 Settings 中配置 MATLAB path 和 GECKO_HOME。
4. 运行 Deep Check。

### 7.3 首次启动很慢

首次启动会创建 `.venv` 并安装 Python 依赖。网络较慢时会更久。

查看日志：

```text
.streamlit_logs\bootstrap_desktop_env.log
```

### 7.4 SAMMI 为什么没有直接出图

当前实现是：

```text
Python backend generates SAMMI-compatible package
```

不是：

```text
Embedded SAMMI viewer renders PNG/SVG automatically
```

也就是说，当前已经有可视化数据层，但自动渲染图片还属于后续模块。

### 7.5 可以删除 run 吗

当前不提供永久删除。DataHub 支持 safe archive / restore：

- archive：移到 `archived_runs`
- restore：从 `archived_runs` 恢复到 `user_runs`

这样更安全，也便于审计。
