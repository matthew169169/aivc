# Multi-Omics Conflict QC

This module compares transcriptomics-derived reaction evidence with
relative-proteomics-derived reaction evidence.

It is designed as a caution layer. When modalities disagree, the router should
make the disagreement visible instead of silently deleting or forcing a
reaction.

## Inputs

Generated reaction-level tables:

- `reaction_expression_evidence.csv`
- `relative_protein_reaction_evidence.csv`

Both tables use the same transparent GPR aggregation convention:

- `AND = min`
- `OR = max`

## Conflict Rules

Strong conflicts:

- `transcript_low_protein_high`
- `transcript_high_protein_low`

Agreements:

- `agreement_high`
- `agreement_medium`
- `agreement_low`

Partial disagreements:

- one modality is `medium`, while the other is `high` or `low`

## Consensus Policy

The consensus evidence is deliberately conservative:

- high + high -> `high`
- low + low -> `low`
- high/low conflict -> `medium`
- medium mixed with high or low -> `medium`
- one usable modality only -> use that modality

This prevents a single transcriptomics low call from deleting a reaction when
relative proteomics suggests the enzyme is increased, while also avoiding an
automatic hard keep without phenotype or flux validation.

## Downstream Evidence Modes

Context feasibility and TROPPO FASTcore can now choose the evidence source with
`--evidence-mode`:

- `transcriptomics`: uses the original RNA-seq / microarray reaction evidence.
- `relative_proteomics`: uses relative-proteomics reaction evidence.
- `consensus`: uses conservative transcriptomics + relative-proteomics consensus evidence.

The E. coli demo pipeline defaults to `consensus` for the context feasibility
and TROPPO steps. This makes multi-omics conflict handling affect downstream
model reconstruction, while keeping the older single-modality modes available
for comparison runs.

For a direct comparison of the downstream inputs created by each mode, run:

```powershell
python tools\compare_evidence_modes.py
```

See `docs\EVIDENCE_MODE_COMPARISON.md` for the generated comparison tables.
