# Relative Proteomics Evidence

This module turns relative proteomics into context-specific reaction evidence.

Relative proteomics is treated differently from absolute proteomics:

- it should not create absolute flux upper bounds by itself;
- it can support reaction weights, FASTCORE core reactions, and CORDA
  confidence tiers;
- it can be combined with transcriptomics for condition-specific model
  extraction.

## Input

Default E. coli demo input:

```text
examples\ecoli\ecoli_relative_proteomics.csv
```

Minimum columns:

```text
protein_id,sample,value
```

Recommended columns:

```text
protein_id,sample,value,unit,condition,reference_condition,gene_id,note
```

Supported value conventions:

- `log2_fold_change`, `log2_fc`, `log2fc`, or empty unit: value is interpreted
  as log2 fold-change.
- `fold_change`, `ratio`, or `fc`: value is converted with `log2(value)`.

## Outputs

Generated by:

```powershell
python tools\build_ecoli_demo_constraints.py
```

Files:

- `relative_protein_evidence.csv`: mapped protein/gene-level log2 fold-change.
- `relative_protein_reaction_evidence.csv`: GPR-aggregated reaction evidence.
- `relative_protein_imat_reaction_weights.csv`: iMAT-compatible weights.
- `relative_protein_fastcore_core_reactions.csv`: FASTCORE core candidates.
- `relative_protein_corda_reaction_confidence.csv`: CORDA confidence tiers.
- `relative_protein_context_reaction_policy.csv`: lightweight context feasibility policy.
- `relative_protein_context_keep_reactions.csv`: relative-proteomics keep/support reactions.
- `relative_protein_context_delete_candidates.csv`: relative-proteomics low-confidence deletion candidates.
- `relative_protein_context_policy_summary.csv`: per-condition policy summary.

## Classification

Default thresholds:

- `high`: log2 fold-change >= 1
- `low`: log2 fold-change <= -1
- `medium`: between those thresholds

GPR aggregation follows the same transparent approximation used elsewhere in
the router:

- `AND = min`
- `OR = max`

This makes the output auditable and useful for method selection, while keeping
absolute enzyme-capacity constraints reserved for absolute proteomics plus kcat.
