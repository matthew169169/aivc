# Omics-GEM Studio 快速入门

这份文档给第一次使用的人看，目标是几分钟内把软件打开，并跑通一个 E. coli demo。

## 1. 安装或启动

### 推荐方式：安装器

运行：

```text
Omics-GEM-Studio-Setup.exe
```

安装完成后，从桌面或开始菜单打开 Omics-GEM Studio。

### 便携方式：解压 zip

如果拿到的是 zip 包，先解压，然后双击：

```text
start_omics_gem_studio.bat
```

首次启动可能较慢，因为软件会创建或修复本地 Python `.venv` 并安装基础依赖。

## 2. 语言切换

默认语言是简体中文。

语言选项有两个位置：

- 顶部右侧：`语言 / Language`
- 左侧 sidebar 底部：`语言 / Language` 卡片

如果界面显示英文，可以在这里切回 `简体中文`。

## 3. 页面结构

主界面分为五个工作区：

- `DataHub`：查看 run package、model variants、reports、visualization packages。
- `Workflow Studio`：后续承载模型生产与分析 workflow，目前更多是状态入口。
- `Visualization Studio`：选择模型变体和 overlay，生成 SAMMI-compatible 可视化包。
- `Task Center`：查看任务状态、日志和历史记录。
- `Settings`：查看 Python 后端、MATLAB/GECKO/SAMMI 等外部依赖状态。

## 4. 跑通 E. coli demo

1. 打开软件。
2. 确认语言为 `简体中文`。
3. 进入 `DataHub`。
4. 选择 run：

```text
user_run_20260515_020824
```

5. 查看 model variants，确认能看到：

```text
baseline_gem__all
eflux__glucose_aerobic
fastcore__glucose_aerobic
consensus_context__glucose_aerobic
enzyme_gecko__all
```

6. 进入 `Visualization Studio`。
7. 选择：

```text
Run: user_run_20260515_020824
Variant: baseline_gem__all
Grouping: subsystem
Overlay: transcriptomics_evidence
```

8. 点击生成 SAMMI visualization package。
9. 进入 `Task Center`，查看 `sammi_visualization` job 是否 completed。
10. 打开生成结果：

```text
user_runs\user_run_20260515_020824\visualization_results\sammi\baseline_gem__all\sammi_launch.html
```

## 5. 当前需要知道的限制

- 目前 SAMMI 模块会生成可视化数据包和 HTML 说明页，但还不会自动导出网络 PNG 图片。
- MATLAB / GECKO 是可选高级功能，不影响基础 demo 和 SAMMI-compatible package 生成。
- 如果 Settings 显示 MATLAB 或 GECKO missing，这是正常的，只有使用 GECKO runner 时才需要配置。

## 6. 出问题时看哪里

优先查看：

```text
.streamlit_logs
task_logs
```

在界面中可以进入：

- `Task Center` 查看任务日志。
- `Settings` 查看 Python backend 和外部依赖状态。
