# Omics-GEM Studio 分发说明

更新时间：2026-05-21

## 最推荐发给别人的内容

如果对方只是想使用软件，不参与开发，优先发送：

```text
D:\generate\desktop_installer\Omics-GEM-Studio-Setup.exe
D:\generate\docs\快速入门.md
D:\generate\docs\详细使用手册.md
```

这是当前最接近普通 Windows 软件的分发方式。安装器会安装 Electron 桌面壳、React 前端、FastAPI 后端源码、bootstrap 脚本和基础 requirements。首次启动时会自动准备项目本地 `.venv`。

## 备选：便携 zip 包

如果对方电脑或安全策略不允许运行安装器，可以发送：

```text
D:\generate\desktop_installer\Omics-GEM-Studio-runtime-staging.zip
D:\generate\docs\快速入门.md
D:\generate\docs\详细使用手册.md
```

对方解压后运行：

```text
start_omics_gem_studio.bat
```

## 对方电脑需要提前具备什么

普通使用者需要：

- Windows 10/11
- Python 3.10-3.12
- 首次启动时建议有网络，用于安装 Python requirements

普通使用者不需要：

- Node.js / npm
- Rust / Tauri
- VS Build Tools
- Streamlit

可选高级功能需要手动安装或配置：

- MATLAB：用于 GECKO / MATLAB runner
- GECKO：酶约束模型高级功能
- RAVEN / COBRA Toolbox：部分 MATLAB 生态工具
- solver：高级优化求解器
- SAMMI standalone：后续本地嵌入式可视化增强

这些外部依赖不会被软件自动安装，但会在 Settings 页面中检测并给出安装引导。

## 不建议发送的内容

不要只发送下面这个 exe：

```text
desktop_runtime\win-unpacked\Omics-GEM Studio.exe
```

它只是 Electron runtime，需要同级 backend、bootstrap、requirements 和启动脚本配合。只发它会导致后端找不到。

一般也不建议发送：

```text
.venv
frontend\node_modules
.runtime_cache
.streamlit_logs
task_logs
```

这些是本机环境、缓存或日志，体积大，而且可能包含个人路径信息。

如果要发 demo 数据，可以单独发送：

```text
D:\generate\user_runs\user_run_20260515_020824
```

但如果其中包含真实实验数据或隐私数据，发送前需要先清理。
