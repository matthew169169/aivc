Workflow spec

Input → Model Generator → Analysis → Summary

Model Compare lives inside Model Generator. Resource Atlas lives inside Input.

01

Input

Resource Atlas discovery, user uploads with explicit role/type, Run Package creation, Atlas curated-evidence handoff.

metadata-only / raw-only → provenance or curation only, never direct import.

02

Model Generator

Model + omics dossier, routes: E-Flux, FASTcore, Consensus, GECKO-ready (guarded). Baseline GEM is reference, not a method card.

GECKO-ready needs kcat + protein pool.

03

Analysis

Method workbench: FBA/pFBA, evidence comparison, ML/PCA/LASSO. Aggregates existing outputs — no heavy external auto-run.

04

Summary

Reports, risks, missing items, case QA matrix, Atlas provenance, next-step guidance.

Architecture

FastAPI × React × omics_router

Backend

  • api/main.py — FastAPI app, routes, auth entry (82 endpoints)
  • api/services.py — main service aggregation (417 KB)
  • api/browser_app.py — serves frontend/dist + API on one port, SPA fallback
  • api/resource_curation_workspace.py — typed create/query/execute curation lifecycle
  • api/run_package_resolver.py — read-only package identity & readiness
  • omics_router/ — 30+ domain modules: cobra, gecko, pytfa, ml, qc, constraints
  • .deps_troppo/ — vendored troppo + cobamp adapters

Frontend

  • App.tsx — shell, routing, state, API calls (kept central)
  • features/ — pure display: input, resource-atlas, model-generator, model-compare, analysis, summary, workflow
  • *Adapter.ts — pure data shaping, no fetch / no state
  • domain/ — workflowRouting, caseContext, workflowRuntime, modelCompareWorkspace
  • Build: Vite 7.3.3, 2,488 modules, index-D6lmiGWb.js 847 KB

Data flow

  1. Input upload or Atlas staging creates user_runs/{run_id}.
  2. Model Generator reads run package → variants, summary, comparison artifacts.
  3. Model Compare reads pair summary, annotation groups, graph, ReactionDiff.
  4. Analysis aggregates outputs; Summary renders report + QA matrix + gaps.

Resource Atlas · Model Compare · Generator

Discovery with strict readiness

Resource Lineage Atlas

Default first view: taxonomy-grouped species/strain tree, resource-type child nodes, counts, image placeholders, click → inspector.

Search Results, Landscape, Deep Dive are folded assistants — never steal first paint.

Readiness ladder

ready_for_import = local file or processed matrix only. ready_for_reference, package_ready, metadata_only, raw_data_only, license_limited stay as discovery/curation clues.

ready_violation_count must be 0.

Model Compare

ReactionDiff Difference Map, Constraint Evidence, Behavior, side-by-side. Coverage / ranking / detail rows via adapters; fact layer stays in place.
